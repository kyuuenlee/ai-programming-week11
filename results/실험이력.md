# 실제 응답으로 교체한 실험 이력

2026-11-12, 사용자가 새 대화에서 받은 A/B/함정 응답을 전달했다.
A: 전달한 전체 코드를 그대로 test_ai_A.py로 저장했다.
B: 사용자가 전달한 뒷부분과 일치하는 test_load_scores(1).py 전체를 확보하여 test_ai_B.py로 복사했다.
함정: 사용자 전체 응답을 그대로 test_ai_bug.py로 저장했다.
함정 응답이 요구한 find_max 모듈은 원본 find_max 함수를 그대로 분리하여 제공했다.
B 대화에서 새로 작성된 구현 파일은 실행에 사용하지 않았다. 모든 CSV 비교는 수업 배포 load_scores.py 원본에 대해 수행했다.

A 26 passed / B 11 passed, 1 failed / 함정 5 passed, 2 failed.
원본 코드와 AI 응답을 수정해서 실패를 통과로 바꾸지 않았다.
최초 같은 대화에서 만들었던 A/B 초안은 이번 실제 응답으로 교체했다.
초기 experiments/bug_probe.py는 보조 실험이며, 이번 AI 함정 응답의 통계에 포함하지 않는다.
모델·설정의 동일 여부는 사용자 확인이 필요하다.
