# 12주차 AI와 함께 데이터 분석하고 검증하기

## 데이터
- 출처: 수업에서 배포한 실습용 인공 성적 데이터 `scores_2026.csv` (114행, 5열, UTF-8). 공개 데이터가 아니므로 별도 공개 라이선스는 확인되지 않음.
- 열: 학번(학생 식별 번호), 이름, 반(1반/2반), 과목(수학/영어/프로그래밍), 점수(0~100점 정수).
- 결측 점수 6행은 실제 점수를 알 수 없어서 임의로 평균을 채우지 않고 제외함. 완전히 같은 중복 4행은 한 번만 남김. 반과 과목의 양끝 공백을 제거하고 범위 밖 점수 4행을 제외함.
- 순서: 결측 제거 → 중복 제거 → 공백 제거 → 범위 밖 제거. 114 → 108 → 104 → 100행.
- 인코딩 실습: `scores_2026_cp949.csv`는 `pd.read_csv('scores_2026_cp949.csv', encoding='cp949')`로 읽음.

## 실행
```bash
python -m pip install pandas pytest
python week12/analysis.py
python -m pytest -q week12/test_analysis.py
```
(week12 폴더에서 실행한다면 `python analysis.py`, `python -m pytest -q`)

## 결론
전체 평균은 1반 78.24점, 2반 71.44점으로 1반이 높지만, 과목별로 나누면 수학(1반 60점, 2반 64점), 영어(1반 76점, 2반 79점), 프로그래밍(1반 84점, 2반 88점) 모두 2반이 높다. 1반은 평균이 높은 프로그래밍 수강자가 30명이고 2반은 평균이 낮은 수학 수강자가 30명이므로 과목별 인원 구성이 전체 평균을 뒤집는다. 따라서 전체 평균만 기준으로는 1반, 같은 과목끼리 비교하면 2반이 더 잘했다고 말할 수 있다.
